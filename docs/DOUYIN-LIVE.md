# 抖音直播伴侣接入（Mac）

更新日期：2026-10-26

这份指南把 Mac AI Live 的独立直播画面送进抖音直播伴侣。它适用于“本机素材驱动 + 直播伴侣窗口采集”，不需要独立 GPU。直播伴侣负责向抖音推流；本项目仍在本机运行。抖音官方目前说明 Mac 版支持 Apple 芯片或 Intel、macOS 13 及以上，并支持摄像头、桌面、程序窗口和图片素材采集；窗口采集指南也明确可选浏览器等已打开程序。[Mac 版说明](https://streamingtool.douyin.com/docs/8uxkey2t_mac) · [窗口捕获指南](https://streamingtool.douyin.com/docs/guide_window)

## 首次接入

1. 从[抖音直播伴侣官网](https://streamingtool.douyin.com/?download=true)下载 Mac 版并安装。登录、开播资格和当前版本要求以软件内提示为准。
2. 启动本项目：`python3 -m studio`。工作台是 `http://127.0.0.1:8765/`；抖音竖屏舞台是 `http://127.0.0.1:8765/stage?layout=portrait`。
3. 在 Chrome 单独打开竖屏舞台，尽量把窗口调整为窄而高，只保留这个窗口供采集，避免把工作台、地址栏或个人页面放进直播画面。竖屏舞台固定为 9:16；横屏窗口中会居中显示，直播伴侣里应将程序窗口画面裁切到中央竖屏画布。
4. 打开抖音直播伴侣，登录你自己的抖音账号，进入常规视频直播预览。选择竖屏画布，再选“添加素材 → 程序窗口/窗口捕获”，选择显示“小满 · 直播画面”的 Chrome 窗口，按预览调整填充、裁切和位置。抖音 Mac 版支持浏览器等程序窗口采集；开播页可切换横竖屏。[直播伴侣 Mac 版说明](https://streamingtool.douyin.com/docs/8uxkey2t_mac) · [窗口捕获](https://streamingtool.douyin.com/docs/guide_window) · [开播界面](https://streamingtool.douyin.com/docs/guide_live)
5. 在舞台窗口点一次“启用声音”，再只看直播伴侣预览和音量指示，确认画面完整、声音没有回授或重复。抖音 Mac 公告没有明确说明普通开播模式的 Chrome 声音路径；音频选项和行为以本机安装版本预览为准。若没有音量指示或回放听不到声音，先解决音频路由再试播，不要靠外放让 Mac 麦克风二次拾音。[直播伴侣音频采集说明](https://streamingtool.douyin.com/docs/guide_4beqpl4o)
6. 真正开播前，先做一次不公开给观众的本地排练：在工作台录入测试弹幕、审核放行，观察 `/stage` 与伴侣预览；测试完成后再由账号所有者自行确认标题、画面、声音及开播。

## 账号和模型边界

- 官方开播 FAQ 当前列出的电脑开播条件包括：账号能在手机正常视频开播、完成相关实名认证、近期没有封禁或违规记录；政务和媒体账号不支持直播伴侣开播。具体资格可能按账号和平台规则变化，软件内提示为准。[官方开播问题 FAQ](https://streamingtool.douyin.com/docs/qna_start_error)
- 不要进入“PICO/VR 虚拟直播”教程来接这个项目。该官方路径列出 Windows 10 和 RTX 3070 级别显卡等要求；本项目接入的是普通窗口采集，使用本机静帧/动作素材，不是直播伴侣的实时动捕形象模块。[官方虚拟直播设备要求](https://streamingtool.douyin.com/docs/guide_pico_xuni)
- 本项目不会读取抖音直播间弹幕，也不会替你开播。现阶段由场控读取弹幕后手动录入工作台，并审核放行；获得明确、合规的平台事件来源后，才适合增加自动接入。
- v0.5.0 在无视频时增加待机眨眼和说话嘴部轻微开合；说话变化不是音素级同步。吃喝、挥手、点头等动作仍需同一原创角色的本地视频才能连续播放。通用问答、Token API、自动弹幕仍未接入。
- 项目本身可完全离线运行；向抖音推流本身需要网络。AI 角色、规则回答和语音不会因此变成云端实时数字人。

## 当前验收范围

截至 2026-10-26，直播伴侣 Mac 官方说明确认支持 macOS 13+、程序窗口采集和推流；官方开播页说明可切换横竖屏。竖屏舞台代码已设为 9:16 并通过本机浏览器测试。桌面端登录后的窗口源选择、伴侣预览和声音回路尚未验收；当前需要账号所有者扫码登录后继续，未开播。
