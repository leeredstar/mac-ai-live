# 抖音直播伴侣接入（Mac）

更新日期：2026-10-25

这份指南把 Mac AI Live 的独立直播画面送进抖音直播伴侣。它适用于“本机素材驱动 + 直播伴侣窗口采集”，不需要独立 GPU。直播伴侣负责向抖音推流；本项目仍在本机运行。抖音官方目前说明 Mac 版支持 Apple 芯片或 Intel、macOS 13 及以上，并支持摄像头、桌面、程序窗口和图片素材采集；窗口采集指南也明确可选浏览器等已打开程序。[Mac 版说明](https://streamingtool.douyin.com/docs/8uxkey2t_mac) · [窗口捕获指南](https://streamingtool.douyin.com/docs/guide_window)

## 首次接入

1. 从[抖音直播伴侣官网](https://streamingtool.douyin.com/?download=true)下载 Mac 版并安装。登录、开播资格和当前版本要求以软件内提示为准。
2. 启动本项目：`python3 -m studio`。工作台是 `http://127.0.0.1:8765/`，独立直播画面是 `http://127.0.0.1:8765/stage`。
3. 在 Chrome 单独打开 `/stage`，把窗口调整到竖屏构图。画面第一次播放声音前，点一次“启用声音”。仅保留这个舞台窗口供采集，避免把工作台、地址栏或个人页面放进直播画面。
4. 打开抖音直播伴侣，登录你自己的抖音账号，进入常规视频直播预览。若界面提供横竖屏画布选项，选择竖屏；再选“添加素材 → 程序窗口/窗口捕获”，选择显示“小满 · 直播画面”的 Chrome 窗口，按预览调整填充、裁切和位置。抖音指南描述的窗口捕获就是选择已打开的浏览器或视频播放器窗口。[直播伴侣开播界面说明](https://streamingtool.douyin.com/docs/guide_live)
5. 在舞台窗口点一次“启用声音”，再只看直播伴侣预览和音量指示，确认画面完整、声音没有回授或重复。抖音通用音频说明介绍了扬声器输出采集，但 Mac 版公告没有明确承诺普通开播模式会采集 Chrome 窗口声音；具体选项和行为以本机安装版本为准。若没有音量指示或回放听不到声音，先解决音频路由再试播，不要靠外放让 Mac 麦克风二次拾音。[直播伴侣音频采集说明](https://streamingtool.douyin.com/docs/guide_4beqpl4o)
6. 真正开播前，先做一次不公开给观众的本地排练：在工作台录入测试弹幕、审核放行，观察 `/stage` 与伴侣预览；测试完成后再由账号所有者自行确认标题、画面、声音及开播。

## 账号和模型边界

- 官方开播 FAQ 当前列出的电脑开播条件包括：账号能在手机正常视频开播、完成相关实名认证、近期没有封禁或违规记录；政务和媒体账号不支持直播伴侣开播。具体资格可能按账号和平台规则变化，软件内提示为准。[官方开播问题 FAQ](https://streamingtool.douyin.com/docs/qna_start_error)
- 不要进入“PICO/VR 虚拟直播”教程来接这个项目。该官方路径列出 Windows 10 和 RTX 3070 级别显卡等要求；本项目接入的是普通窗口采集，使用本机静帧/动作素材，不是直播伴侣的实时动捕形象模块。[官方虚拟直播设备要求](https://streamingtool.douyin.com/docs/guide_pico_xuni)
- 本项目 v0.3.4 不会读取抖音直播间弹幕，也不会替你开播。现阶段由场控读取弹幕后手动录入工作台，并审核放行；获得明确、合规的平台事件来源后，才适合增加自动接入。
- 没导入同一角色的动作视频时，所有动作都保持静帧并标明缺少素材；不会把姿态图冒充成吃喝或挥手动画。通用问答、Token API、自动弹幕仍未接入。
- 项目本身可完全离线运行；向抖音推流本身需要网络。AI 角色、规则回答和语音不会因此变成云端实时数字人。

## 当前验收范围

2026-10-24 在隔离数据目录和本机 8766 端口验证了队列审核、开始排练、独立舞台接收弹幕和本地规则回答；10 项 Python 自动化检查全部通过。隔离测试没有改动 8765 的排练队列。直播伴侣官网文档和 Mac 下载包已核实；本机应用虽已安装，但自动化工具无法读取其窗口，本次没有完成伴侣登录、窗口捕获、声音回环或真实推流验收。因此已核实官方支持的接入路径，尚不能称为端到端直播验证。
