# v0.2.2 角色素材预览体验验证（通过）

日期：2026-10-24（Asia/Shanghai）。环境：Apple Silicon M4、macOS、Python 3.9.6。

## 本轮目标

- 将 16:10 直播画面换为原创虚构成年女性写实静帧，保留人物、桌面、饼干与茶杯。
- 增加本地演示标识、弹幕展示卡、互动状态卡和本地视频素材就绪提示；静帧、语音和视频素材能力如实分开。
- 工作台每个动作显示本地视频是否已导入；缺少素材时提供直达素材页的入口，并说明人物仍是静帧。
- 角色素材页在缺少动作视频时显示同一原创角色的静帧预览，并用覆盖标签明确标出未导入动作视频。
- 侧栏版本号与公开发布版本保持一致。
- 桌面 Chrome 检查独立画面及工作台预览；验证弹幕状态切换与无素材回退。

## 本轮通过

- 8 项 Python 定向检查全部通过；覆盖审核队列、动作中断、存储恢复、媒体导入和来源校验。
- 工作台和直播画面的 JavaScript 语法检查及 `git diff --check` 通过。
- 角色缩略图以本地 420×262 JPEG 提供；本机 HTTP 返回 200，体积约 36 KB。
- 本机 HTTP 返回新静帧和更新后的独立直播页面；桌面浏览器从工作台打开直播画面，图像加载成功，品牌、弹幕卡、状态提示和离线标识可见。工作台未导入动作视频时显示素材状态与静帧说明。
- 工作台显示“本地视频素材 0/7 项已就绪”；七个动作均标注“无动作视频”，点击“准备素材”进入角色素材页。角色素材页以同一张写实静帧预览各动作，并明确标出视频缺失。
- 桌面 Chrome 实际检查确认预览缩略图加载，人物面部完整可见；图片不再因延迟加载显示为空黑块。
- 横画布维持 16:10；窄画布自动切换 9:16 构图。写实画面没有素材视频时保持静帧，并明确标注。
- 原有待审互动仍在队列中，没有被验收操作放行、跳过或清除。

## 本轮边界

- 写实人物是单张 AI 静态图片；不会眨眼、咀嚼或按台词对口型。动作须导入同一人物的本地视频。
- 曾尝试把三张 AI 姿势图补帧成动作视频；吃、喝片段有明显重影和脸部变形，因此未纳入应用或发布包。
- 目前没有随应用附带的真实动作视频，尚不能验收真实吃喝效果、人物连续性或真人身份相似度。
- 本轮只切换桌面工作台页面、刷新本地界面和读取 API；未操作任何队列按钮，未打断当前排练或已有声音。
- 没有生成视频、没有用目标主播本人照片或声音。
- 未连接抖音或 OBS，未执行真实推流。
