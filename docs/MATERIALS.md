# 第一套角色素材清单

先准备一个角色、一个桌面场景、一种食物。所有素材使用一致的镜头位置、人物衣着、光线、背景和画幅，尽量让动作起止回到同一个基准姿势。

| 槽位 | 内容 | 建议长度 | 播放方式 |
| --- | --- | --- | --- |
| 待机 | 看向镜头、呼吸、眨眼、轻微低头 | 10–25 秒 | 循环 |
| 说话 | 正对镜头，嘴部和身体轻微活动 | 10–25 秒 | 循环，无精确口型 |
| 吃一口 | 手拿食物、咬一口、咀嚼、放下、回到待机 | 5–12 秒 | 完整一次，随后语音 |
| 喝水 | 拿杯、喝水、放下、回到待机 | 4–8 秒 | 完整一次，随后语音 |
| 挥手 | 举手打招呼，回到待机 | 3–6 秒 | 随语音循环 |
| 笑一笑 | 轻笑，再回到待机 | 3–6 秒 | 随语音循环 |
| 点头 | 一个自然的点头 | 2–4 秒 | 随语音循环 |

注意食物数量变化。素材每次重播会重置食物状态，当前不模拟连续吃掉同一份食物。若食物明显变少，应按不同状态分别制作，后续再增加道具状态调度。

支持 H.264 MP4 / WebM，0.1–120 秒、150 MB 以内。程序会验证视频流与时长，视频原声不会播放。建议 720p 或 1080p，25/30 fps。

第一版不必准备大量素材，先验证待机、说话、吃一口的衔接。没有人物视频时，舞台显示内置写实静帧；吃东西状态会切换一张原创姿态参考图，但仍是静态画面。互动队列和语音可以排练，连续身体动作需要本地视频素材。

## 后续所需

1. 你有权使用的人物形象和动作视频。
2. 确定后续模型服务、API 地址、模型名和 Token；Token 只配置在本机。
3. 若接真实抖音弹幕，需要可用且获准的采集/事件来源。
4. 若开播，需要 OBS 或直播伴侣、账号输入权限和本机音频捕获配置。
