# 小满 · Mac AI Live

**在 Mac 上运行的离线虚拟主播工作台。Python 标准库后端，无需独立 GPU、CUDA、云服务或 API Key。**

手动弹幕 → 审核放行 → 本地规则回答 → Mac 中文语音 → 静帧或本地视频直播画面。

> **这是素材驱动原型，不是实时生成写实数字人的模型。** 内置原创写实静帧角色可直接排练；导入同一人物的本地视频后，才能看到对应动作。默认回答由规则生成，不具备通用大模型问答。尚未自动连接抖音弹幕，也不会自动开播。

## 在 Mac 上启动

要求：macOS、Python 3.9+。在 Apple Silicon Mac 上开发验证；不调用 GPU 推理。

```sh
git clone https://github.com/leeredstar/mac-ai-live.git
cd mac-ai-live
python3 -m studio --open
```

也可以在 Finder 中双击 `start.command`。如果 Git 下载工具没有保留执行权限，先执行 `chmod +x start.command`。无 Python 依赖需要安装；Python 可从 [python.org](https://www.python.org/downloads/macos/) 安装。

- 工作台：<http://127.0.0.1:8765>
- 独立直播画面：<http://127.0.0.1:8765/stage>
- 退出：运行程序的终端中按 `Ctrl+C`。
- 换端口：`python3 -m studio --port 8766 --open`。

### 第一次排练

公共安装包不包含真人动作视频。首次启动可以直接排练弹幕、回答、字幕与语音；吃东西时会切换到一张原创静态姿态图，其他未导入视频的动作仍保持静帧。要看到连续的吃、喝或挥手动作，请在“角色与动作”中导入同一人物且你有权使用的本地视频。

1. 打开独立直播画面，点一次 **启用声音**。工作台内的预览始终静音，避免回声。
2. 在工作台点 **开始排练**。
3. 输入一条弹幕，或点 **吃一口 / 挥挥手 / 喝口水**（没有对应视频时只排练互动状态，人物不会动）。
4. 在候场队列点 **放行**。
5. 吃、喝动作先完成，随后播放语音和字幕；挥手、点头等可配合语音一起播放。

**暂停** 会取消当前表演、保留等候队列；**方形停止按钮** 中断当前表演，继续下一条已放行的弹幕；**清空** 中断当前表演并取消队列。已跳过、取消和失败的记录会保留，便于排障。重启后待审核和已放行任务会恢复到队列；退出时正在表演的任务会取消，避免重复播放。

## 当前能做什么

| 能力 | 状态 |
| --- | --- |
| 原创写实静帧、弹幕卡和回答状态 | 已实现；吃东西缺视频时切换姿态参考静帧，不产生连续动作 |
| 每个动作替换为本地视频；切换时交叉淡入 | 已实现，素材连续性由你准备 |

| 弹幕队列、审核、跳过、去重、暂停、中断 | 已实现，队列最多 30 条 |
| 控制台与独立直播画面同步 | 本机 SSE；多窗口共用状态 |

| 自由问答 / Token API | 后续接入；当前无云端模型请求 |
| 真实抖音弹幕 | 尚未实现平台连接；提供本机 JSON 接入口 |
| 写实角色实时生成、真实咀嚼物理、精确口型同步 | 不包含 |
| 抖音直播伴侣 | Mac 普通模式可按程序窗口采集 `/stage`；账号、声音与实际推流未端到端验收，见 [Mac 接入指南](docs/DOUYIN-LIVE.md) |

## 替换为写实角色

在 **角色与动作** 中，可以分别导入动作短视频，也可以在剪辑台导入一段长视频，预览后填写起止时间，选择动作并剪成对应片段。需安装 [FFmpeg](https://ffmpeg.org/) 用来验证和裁剪视频，已有 Homebrew 时可运行：

```sh
brew install ffmpeg
```

- 原视频支持 **H.264 MP4** 或标准 **WebM**，最长 **30 分钟**、最大 **150 MB**；剪辑台生成 **0.25–120 秒**的 H.264 MP4，每段最大 **150 MB**。
- 剪辑和转码都在 Mac 本机 CPU 完成；原视频声音会去除，语音仍由 Mac 单独生成。剪完后可以移除临时原视频，生成的动作片段会保留。
- 建议固定人物、镜头、桌面和光线，使用统一画幅。内置示例按 16:10 构图，16:9 输出也可。
- 待机、说话片段循环播放；吃、喝片段按实际素材时长完整播放一次。
- 视频原声静音，音频由 Mac 中文声音统一提供。
- **说话视频是循环素材，不会按新台词重新生成嘴型。** 当前写实静帧不做口型动画。
- 缺少某动作时，有待机视频素材则退回待机；没有待机视频时继续显示写实静帧。吃东西另有一张静态姿态参考图，不代表连续动作。
- “恢复示例”解除素材绑定，原视频文件仍保留在 `data/media/`，不会自动删除用户素材。

当前工作台附有原创虚构成年女性写实静帧及一张吃东西姿态参考图，直播画面会显示弹幕、回应阶段和本地演示标识；宽画面按 16:10 展示，窄画面自动裁切成 9:16 预览。姿态图只是状态切换，需导入同一人物的本地动作视频才能呈现连续吃、喝、挥手等动作。

详见 [素材拍摄清单](docs/MATERIALS.md)。

## 弹幕入口

目前可手动录入，也可由你自己的本机采集程序推送。此接口**不会替你获得抖音弹幕权限**。

```sh
curl http://127.0.0.1:8765/api/comments \
  -H 'Content-Type: application/json' \
  -d '{"user":"小伙伴","text":"小满，吃一口饼干吧"}'
```

默认进待审队列，在工作台放行。可以在设置中开启新弹幕自动放行；正式使用前建议保留审核。本机其他网页不能跨站调用；服务器绑定 `127.0.0.1`，不提供公网端口、身份验证或多用户隔离。

## 模型以后再接

默认规则模式，无需任何 Token。`Studio.reply()` 是回答生成入口，和语音、素材、画面输出解耦，可以后续替换成 OpenAI 兼容接口或其他模型服务；密钥应从本机环境变量读取，不能提交仓库。**当前版本没有实现或测试云端 API。**

已有本地 Ollama 时，可在设置选择该模式、填入已安装的模型。固定访问 `127.0.0.1:11434`，请求明确设置 `num_gpu: 0`；不自动下载模型。CPU 推理可能慢，生成调用超时为 90 秒，生成期间中断会先让画面回到待机，但下一任务可能要等模型调用返回。本项目不附带模型，不要求安装 Ollama。

## 直播画面与声音

可用 Chrome 打开 `/stage`，启用声音，然后在 OBS 或抖音直播伴侣中捕获该程序窗口。伴侣 Mac 版支持窗口采集；其公开 Mac 说明没有明确普通直播的窗口音频采集方式，声音必须在伴侣预览里单独确认。OBS 音频需要另行捕获浏览器应用音频或系统音频并监听确认；不同 OBS/macOS 版本行为不同。工作台预览不会发声；同一浏览器的多个独立画面窗口通过 Web Locks 尽量只保留一个音频输出。

接入抖音前，核对账号开播、直播伴侣输入方式以及数字人相关要求，画面保留 AI 标识。当前没有代操作账号或推流。操作步骤见 [抖音直播伴侣 Mac 接入指南](docs/DOUYIN-LIVE.md)。

## 数据与发布边界

- 程序运行不连接外网；选择 Ollama 才访问本机模型服务。
- 配置、素材与最近互动存放在 `data/`，已加入 `.gitignore`，不上传 GitHub。
- 自定义数据目录：`MAC_AI_LIVE_DATA=/your/local/folder python3 -m studio`。
- 本地语音只保留最新 60 个 WAV；互动数据库不自动清理。请按需要备份/管理 `data/`。
- 素材只经由本机浏览器传给本机程序，不发送第三方服务。
- 公共仓库只含原创代码、原创 AI 写实静帧和文档。人物是原创虚构成年人，不是对主播本人做身份复刻；没有复制天工开帧的程序、人物形象或声音。
